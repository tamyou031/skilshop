# スキルマーケット型サイト（ECサイト）
複数のユーザーが、提供するサービスを作り公開するという機能をメインに実装しました。  
その他にも、サービスに対する口コミの投稿やサービス名の検索なども可能です。

# 主に実装した機能
・ユーザー登録（サインアップ）  
「新規登録」からフォームにユーザー名、パスワード、メールアドレスを登録すると、  
サービスや口コミを制作するのに必要なユーザーを登録することができます。　　

  
・ログイン、ログアウト  
「ログイン」にて、登録したメールアドレスとパスワードを使用することでログインでき、  
サービスや口コミの制作・投稿や確認が可能です。  

  
・サービスの作成、更新、削除  
ログインした状態で出品するサービスを作成することができます。  
作成した後のサービスは自身が制作したものであれば、自由に更新と削除が可能です。  


・サービスの検索  
サイト上部にある検索窓にサービス名のタイトルを入力（部分的でも可）し検索ボタンをクリックすると、  
該当したタイトルのサービスを表示します。
